# 📊 Amazon Sales Analysis Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive **Amazon Sales Analysis Dashboard** developed using **Microsoft Power BI**.

The dashboard provides a comprehensive view of sales performance by analyzing key business metrics such as sales, quantity, profit, shipping cost, country, city, market, category, and shipping mode.

The goal of this project is to transform raw sales data into meaningful visual insights that can support business decision-making.

---

## 🎯 Objectives

- Analyze overall sales performance.
- Track total sales, quantity, profit, and shipping costs.
- Identify top-performing countries and cities.
- Analyze sales across different markets.
- Compare different shipping modes.
- Understand category-wise sales performance.
- Create an interactive and user-friendly dashboard.
- Identify trends and patterns to support business decisions.

## 📊 Dashboard Features

### 1. Sales by Country
Analyzes sales performance across different countries and highlights the highest-performing markets.

### 2. Sales by Ship Mode
Compares sales generated through different shipping modes:

- Standard Class
- Second Class
- First Class
- Same Day

### 3. Sales by City
Displays sales performance across major cities and helps identify high-performing locations.

### 4. Sales by Category
Provides category-level sales analysis and allows users to filter the dashboard by category.

### 5. Sales by Market
Analyzes sales across different global markets, including:

- APAC
- LATAM
- EU
- US
- EMEA
- Africa
- Canada

### 6. Interactive Filters
The dashboard includes interactive filters that allow users to explore sales performance based on different categories and dimensions.

---

## 🔍 Key Insights

- The United States is one of the highest-performing countries in terms of sales.
- Sales vary significantly across different cities and markets.
- Standard Class shipping contributes the largest share of sales among the available shipping modes.
- Different global markets contribute differently to overall sales.
- The dashboard enables easy comparison of business performance across multiple dimensions.
